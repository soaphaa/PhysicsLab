# PhysicsLab

An interractive web application for learning introductory High school physics through visual simulations and structured lessons, built by a high schooler.

**Access the website here!** : [PhysicsLab vercel app](https://physics-lab-ten-peach.vercel.app/index.html#)

🚧 **Currently in Beta** - This project demonstrates key kinematics concepts with 4 interactive simulations. Future updates will include more lessons, more physics units (circular motion, energy, waves), and expanded practice problems. 🚧 


## Features
- **Interactive Simulations** : Real time physics visualizations for (currently) Kinematics and projectile motion.
- Dropping objects from a height
- Throwing objects up
- Demonstration of acceleration through car movement

- **Lessons** : step by step tutorials with the simulations within them, covering fundimental concepts and equations
- **Practice problems** : Test your understanding with Physics questions
- **Formula Sheet** : A reference formula sheet for key equations

## Key Technologies
- JavaScript
- HTML5
- requestAnimationFrame for smooth animations in the simulations.

## File Sizes & Assets
- All images are placed in the assets/ folder

## Navigation
The website can be navigated through the top bar and the homepage. This is where all features are easily accessible and findable.
